# examples/

Runnable examples. Every output shown in the example script's
documentation is captured from a real run.

| File | What it demonstrates |
|---|---|
| [run-example.sh](run-example.sh) | The full CLI surface against this kit's own tree: check, publish, and the secret gate refusing an allowlisted file in a scratch copy. |
| [private-source/](private-source/) | The mode 1 source fixture: two guides with a private design pointer and a private-relative link. |
| [public/](public/) | The mode 1 derived copies (GENERATED by `docpol sync`; do not edit). |
| [public-published/](public-published/) | The mode 2 published tree (GENERATED by `docpol publish`; do not edit). |
| [allowlist.json](allowlist.json) | The mode 2 allowlist that drives the publish. |
| [demo-secret-file.md](private-source/demo-secret-file.md) | A synthetic, self-labeled demo file used by the test suite to exercise the secret gate. It is NOT allowlisted, and no pattern in it is a live credential. |

Run it:

```bash
bash examples/run-example.sh
```

The two generated trees are artifacts of the engine's own demo pair; both
are rebuilt by the sync and publish commands and are safe to delete.
